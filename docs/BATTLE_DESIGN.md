## 2. 제안 — 콜에서 여기에 반응해줘

### 2.1 런칭 시점 배틀 타입

**제안: 딱 하나 — 1v1 점수 배틀.** 러너 둘, 정해진 기간, 누적 배틀 점수 높은 쪽이 승리. 거리 전용 모드 없음, 그룹 모드 없음, 공개 배틀 없음.

*이유:* 모드 하나 = 리더보드 로직 하나, 정산 경로 하나, 실유저로 밸런싱할 대상 하나. 그룹/크루 배틀은 명백한 v1.1 (크루 인프라 + 초대 링크가 이미 있어서 얹기 좋음).

### 2.2 라이프사이클 — 5단계

```
초안(DRAFT) → 대기(PENDING) → 진행(ACTIVE) → 정산(SETTLING) → 종료(SETTLED)
                    ↘ 만료(EXPIRED) — 초대 48시간 무응답
              진행 ↘ 포기(FORFEITED) — 명시적 항복 → 즉시 패배
```

1. **초안** — 생성자가 설정: 상대, 기간 (프리셋 칩: 3 / 7 / 14 / 30일), 선택적 타이틀 (자유 텍스트, 예: "청라 대전"). v1에 커스텀 스코어 룰 없음.
2. **대기** — 초대 전송. 상대 수락 → 진행 (시계는 수락 시점 기준, 다음 KST 자정 정렬 — 2.5 참고). 거절 → 종료. 48시간 무응답 → 만료.
3. **진행** — 자격 런 (≥1.5km, 저장)은 전부 자동으로 배틀에 스코어링. "이 런을 배틀에 제출" 같은 수동 단계 없음 — 런은 진행 중인 모든 배틀에 자동 반영. 양쪽 다 라이브 리더보드 확인 가능.
4. **정산** — 기간 종료; 서버가 **30분 유예** (오너 룰링 8/29, 어드바이저 2시간 권고 기각) 동안 늦은 저장을 기다린 뒤 최종 점수 계산, 스트릭 멀티플라이어 적용, 결과 확정. **필수 조건:** 30분 저장 마감이 배틀 룰 UI에 명시돼야 함 — 기간 종료 후 30분 내 저장된 런만 카운트. 지연의 싱크 지연 데이터가 반박하면 콜에서 재론; 아니면 종결.
5. **종료** — 결과 불변. 승자 배너, 점수 상세, 리매치 버튼.

### 2.3 방치 처리 (침묵 문제 — 기존 스펙에 없던 것)

포기는 명시적 행위. 근데 그냥 안 뛰면?

**제안: 스코어보드 외 페널티 없음.** 안 뛰는 상대는 남은 기간 0점으로 쌓여서 점수로 패배. 자동 몰수 없음, 알림 (2.7) 외 잔소리 메커니즘 없음. 기간 끝나면 정상 정산.

*이유:* 침묵을 자동 몰수 처리하면 부상당한 사람, 바빠진 사람을 처벌하는 것과 구분이 안 됨. 스코어보드가 이미 침묵을 비례적으로 처벌함. 상태 머신도 단순해짐.

**탈출구 하나:** 상호 취소 — 어느 쪽이든 취소를 *제안*할 수 있고, 상대가 수락하면 배틀 무효 (승패 기록 없음). 일방적 이탈은 여전히 포기 = 패배.

### 2.4 안티치트 v1 (배틀은 치팅 유인을 만듦 — 기존 스펙에 없던 것)

**제안 — 런칭 시점엔 차단이 아니라 표시-제외:**
- 페이스 상한: 평균 페이스 **2:30/km**보다 빠른 런은 배틀 스코어링에서 제외 (일반 런으로는 정상 저장) + 배틀 상세에 "검증 제외" 중립 표시
- 속도 스파이크: 지연 쪽 픽스 스트림 개연성 체크 (기존 필터링 인프라 활용) — 같은 제외 처리
- v1에 신고 UI, 이의제기 플로우 없음. 제외된 런은 양쪽 다 사유와 함께 보임.

*이유:* 조용히 제외하면 불신이 자람; 보이되-중립적인 제외는 재판소 없이 규범을 세움.

### 2.5 시간 · 공정성 엣지

- **모든 배틀 시계는 KST** (서버 기준, 기기 타임존 무관). 런의 배틀-일은 시작 시각의 KST 기준.
- **날짜 경계:** 배틀 "일"은 KST 달력일. 수락 시 활성화되고, 1일차 = 다음 KST 자정부터 (양쪽이 항상 동일한 온전한 날들을 가짐). 콜 룰링 필요: 부분-일 포함 즉시 시작 vs 자정 정렬. **제안: 자정 정렬.**
- **얼리버드** (+10, 07:00 이전)는 KST 07:00 기준.
- 런 하나가 자격 되는 **모든** 진행 중 배틀에 동시 스코어링 (배타성 없음).

### 2.6 화면 (FE 범위 — 기존 쉘 확장)

1. **배틀 홈** (`battle-preview.tsx` 확장) — 탭: 진행 중 / 대기 / 종료. 카드에 상대, 남은 일수, 점수 격차.
2. **생성 플로우** (`battle-create-demo.tsx` 확장) — 상대 선택 (친구 목록; 맞팔 필수 — 룰링 2.8-Q3), 기간 칩, 타이틀, 확인.
3. **초대 화면** — 받은 초대: 상대 프로필, 조건, 수락/거절. 푸시 + 인앱.
4. **배틀 상세 (진행 중)** — 메인 화면: 점수 바 (나 vs 상대), 일별 상세, 런 목록 + 런당 점수, 남은 일수, 포기는 오버플로우 메뉴에 (메인 버튼 X — 실수 항복 방지).
5. **정산 화면** — 결과, 점수 상세 나란히, 스트릭 효과, 리매치 CTA.
6. **신고/차단** — 배틀 컨텍스트의 상대 프로필에서 진입 (소셜 기능에 대한 Apple 필수 요건). 기존 프로필 신고 기능 재사용/확장; 없으면 이 배틀 슬라이스에서 최소 버전 추가 필수.

### 2.7 알림 (푸시 — 빌드 13 expo-notifications에 탑승)

런칭 최소셋, 전부 배틀 범위:
1. 초대 수신
2. 초대 수락 (배틀 시작)
3. 상대가 런 기록 / 역전당함 (**빈도 제한: 배틀당 하루 최대 1회** — 제안)
4. 마지막 날 리마인더
5. 정산 완료 — 결과

스트릭 잔소리 없음, "요즘 안 뛰시네요" 죄책감 푸시 없음 (v1).

### 2.8 오픈 질문 — 콜에서 반드시 룰링

- **Q1. 리매치:** 같은 조건 원탭 리매치 — v1 포함 or 이후? (생성 플로우가 파라미터화돼 있으면 저렴함; **포함 제안.**)
- **Q2. 전적 공개 범위:** 종료된 배틀이 공개 프로필에 보이는가 (승/패 기록)? 제안: **v1은 비공개** — 참가자끼리만. 공개 전적은 문화를 이해하기 전에 판돈과 독성을 키움.
- **Q3. 대전 가능 범위:** 맞팔만, 팔로우하는 사람 전부, 아니면 오픈 초대 링크? 제안: **v1은 맞팔만** (스팸 안전, 낯선 사람 괴롭힘 표면 없음; 초대 링크는 크루 배틀과 함께 v1.1).
- **Q4. 정산 유예 시간: 종결 — 30분** (오너 룰링 8/29, 어드바이저 2시간 권고 기각). 기간 종료 +30분에 정산 계산; 그 이후 저장된 런은 자정 전 시작이어도 미포함. 배틀 룰 UI에 명시 필수. 지연 데이터에서 40분+ 지각 저장이 흔하면 재론.
- **Q5. 페이스 보너스 커브:** 확정된 공식에 "페이스 보너스"라고만 있고 커브는 스펙에 없음. 지연의 `battle-score.ts`에 *뭔가* 구현돼 있음 — 콜에서 실제 구현된 커브를 소리 내서 읽고, 합의하고, 스펙으로 기록하자.
- **Q6. IAP 게이팅: 종결 — 지연 스펙 8/29, Ivan 채택:**
  - 베타: 전원 무제한
  - 무료 유저: 1:1 배틀 관여 (생성+수락 합산) **최근 30일 롤링 3회**까지
  - 프리미엄: 무제한
  - 그룹 배틀: v1.1 (월 1개, 정책은 그때)
  - 카운팅: 생성과 수락 모두 포함, 배틀당 참여일 기준 30일 롤링
